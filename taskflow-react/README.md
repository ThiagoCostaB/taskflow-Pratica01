# TaskFlow React

Aplicação desenvolvida em React para gerenciamento de tarefas.

## Tecnologias

- React
- React Router DOM
- Context API
- Axios
- CSS

## Funcionalidades

- Cadastro de tarefas
- Listagem de tarefas
- Exclusão de tarefas
- Alteração de status
- Estado compartilhado
- Integração com API REST
- Responsividade

## Instalação

npm install

## Execução

npm run dev
